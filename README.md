# תכנית עבודה — Work Planner

אפליקציית Gantt לתכנון עבודה עם ניהול פרויקטים מרובים.

## הפעלה

1. הורד את שני הקבצים לאותה תיקייה
2. פתח את `te_projects.html` בדפדפן
3. אין צורך בשרת — עובד ישירות מהקובץ

## קבצים

| קובץ | תפקיד |
|------|--------|
| `te_projects.html` | לוח הפרויקטים — נקודת הכניסה |
| `te_planner.html` | עורך ה-Gantt לכל פרויקט |

## פיצ'רים

- ניהול פרויקטים מרובים
- ציר זמן Gantt עם גרירה חופשית
- קבוצות, צוותות ועובדים
- ספרינטים אוטומטיים (גלובלי לכל הפרויקטים)
- אבני דרך
- תלויות בין משימות
- Undo עד 4 פעולות (Ctrl+Z)
- העתקה בין עובדים (Ctrl+C / Ctrl+V)
- סיכום שעות לפי קבוצה + ייצוא Excel
- ייצוא CSV

## נתונים

הנתונים נשמרים ב-`localStorage` של הדפדפן — כל פרויקט בנפרד.

## תוכנית עתידית

- חיבור ל-Firebase לסנכרון בין משתמשים
- אימות משתמשים
